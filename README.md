# 🌸 Iris Flower Classification Using Machine Learning

## 📌 Project Overview
This project predicts the species of Iris flowers using Machine Learning classification algorithms based on sepal and petal measurements.

## 📊 Dataset Description
The dataset contains four input features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

**Target Variable:** Species

Classes:
- Iris-setosa
- Iris-versicolor
- Iris-virginica

## 🚀 Application
An interactive Gradio application allows users to enter flower measurements and predict the Iris species.
